# 📈 Retail Demand Forecasting

## 📌 Project Overview

This project predicts future retail product demand using Machine Learning.

The model was trained using historical retail sales data and deployed using Streamlit.

---

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Joblib

---

## 🤖 Machine Learning Model

Random Forest Regressor

---

## 📊 Features Used

- Product_ID
- Year
- Month
- Revenue
- lag_1
- lag_2
- lag_3
- last_transaction
- Unique_Customers
- Average_Product_Sales

---

## 📈 Model Performance

- MAE = 26.69
- RMSE = 56.58
- R² Score = 0.925

---

## ▶️ Run the Project

```bash
streamlit run app.py
```
